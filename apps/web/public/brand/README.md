# هوية موعد (Mawid brand assets)

- **`icon.svg`** — الأيقونة المربّعة الكاملة، بلا تدوير زوايا. هذا هو ملف
  المصدر الذي يُرفع لمتاجر iOS / Android / Windows — كل نظام يُطبّق قناع
  القصّ الخاص به (مربع دائري الزوايا، دائرة، إلخ)، والرسمة مصمَّمة لتبقى
  داخل "المنطقة الآمنة" لأي قناع.
- **`icon-tile.svg`** / **`icon-1024.png`** — نسخة بزوايا دائرية جاهزة
  للاستخدام المباشر (favicon، بطاقات README، عرض عام على الويب).
- **`wordmark-teal.svg` / `.png`** و **`wordmark-white.svg` / `.png`** —
  كلمة «مَوْعِد» مشكّلة بخط Amiri 700، للخلفيات الفاتحة والغامقة على التوالي.
- **`lockup-teal.svg` / `.png`** — التركيبة الأفقية (أيقونة + كلمة) لرأس
  الصفحة أو شاشة البداية.

الألوان: `#0F7A6C` (تيل أساسي) · `#17A892` (فاتح) · `#0A5A4F` (غامق) ·
`#F5FBF9` (أبيض العلامة).

ملفات `.svg` النصية تعتمد على خط Amiri (Google Fonts) عبر `@import` داخل
الملف نفسه؛ عند التضمين في تطبيق حمّل الخط أيضًا لضمان تطابق العرض.
