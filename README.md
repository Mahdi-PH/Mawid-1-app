# Mawid-1-app

نظام سحابي ومحلي متكامل (SaaS) لإدارة حجوزات العيادات الطبية الصغيرة والمراكز الصحية الخاصة، مصمم خصيصاً ليناسب بيئة العمل الطبية، مع التركيز على البساطة، العمل في ظروف انقطاع الإنترنت، القضاء على التكدس، وتقليل نسبة الغياب.

---

## 🎮 [`duskfront/`](./duskfront) — جبهة الغسق (DUSKFRONT)

لعبة حرب ويب ثلاثية الأبعاد كاملة تعيش في مجلد مستقل داخل هذا المستودع: كوكب يدور ببطء يزحف فيه
خط الغسق عبر الخريطة، فيصبح الضوء نفسه سلاحًا وموردًا ومجالًا للصراع.

```bash
cd duskfront
npm install && npm run dev      # يعمل بلا Postgres ولا Redis
```

التفاصيل الكاملة — البنية، التشغيل عبر Docker، تعديل التوازن، والاختبارات — في
**[`duskfront/README.md`](./duskfront/README.md)**.
